# drafts/

Brain-dumps live here, one per post: `<slug>.brain-dump.md`.

**Nothing in this directory is committed except this file.** Brain-dumps are raw material — they
hold company names, colleague names, unscrubbed logs and internal detail that must never reach the
site. Anonymisation happens when the draft is written, not when the material is collected. See
[docs/WRITING.md §8](../docs/WRITING.md).

`/newpost` creates them. The `drafter` skill reads them. The `fact-checker` skill checks every
number in a draft against the matching brain-dump, so deleting one after publishing means the post
can no longer be verified — keep them.
